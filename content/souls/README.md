# Souls

Persona / value bundles — voice, taste, defaults — that wrap any agent.

## ⚠️ Disclaimer (read first)

Every soul published here is a **fictional, AI-generated persona**. Souls
inspired by real public figures are **NOT the real person** and are not
affiliated with, endorsed by, or representative of them.

**See the full legal text and takedown process in
[`/SOULS_DISCLAIMER.md`](../../SOULS_DISCLAIMER.md).**

The same disclaimer is shipped in the platform UI, in every `SOUL.md` export,
and in the soul JSON API response under the `disclaimer` field. The canonical
source is [`src/lib/souls/disclaimer.ts`](../../src/lib/souls/disclaimer.ts).

## Pricing

Souls are **always free** — pricing is disabled in the UI and enforced at the
database level.
