# Finance preparation uses typed state and source interpretation

Status: implemented candidate; qualification and publication pending.

Repeated real compiled-graph pilots preserved correct arithmetic but confused
budget approval, unmatched-entry ownership and authority to post/pay/sign off.
Later correct drafts did not repair earlier false statements. Full transport
captures disproved lost-input hypotheses. Adding prose instructions and monetary
citations improved individual defects but did not reliably preserve those roles.

Finance therefore uses the existing compiled runtime's real `tool:` actions for
extraction presentation, reconciliation, analysis and human-review handoff. The
pinned TypeSafe interpreter supplies advisory record classifications, literal-value
selections and source-statement attribution. Code performs integer arithmetic,
retains original quotes/probabilities, binds predecessor stages to the same source
evidence and keeps controller review unauthenticated/pending. The tools do not post,
pay, approve or sign. Source approval claims never become operational authority.

No generative model drafts the four finance stage outputs. This is an actual
execution-protocol change, not output repair, a replay or a mock substitute for a
model benchmark. Finance qualification is scoped to `jev-1.14.0`, the pinned Node
host and packaged finance-source-state protocol. It makes no Gemma quality claim.
The other three playbooks continue using the pinned local generator. Agent Match's
same-generator comparison and financial cap are unaffected.

The frozen four-subject/72-case contract, original severities, expectations,
thresholds, primary trace reviews and zero high/critical bar remain unchanged.
Finance evidence must contain a real source-interpretation response with model and
usage plus four actual accounting-tool receipts. The strict reporter rejects any
unexpected finance generation and recomputes each stage from the validated source
evidence. Other playbooks still require complete raw generation transports. No
prior qualification transfers to this protocol; all 72 cases remain required.

Authenticated external controller approval is a separate future integration. Until
it exists, a successful graph prepares a closing pack and preserves the pending
human gate. It cannot claim that the business month is signed off.
